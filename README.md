# Karanlık Ev

Selim adlı karakterin başrolde olduğu 2.5D korku oyunu.

## İndirme ve kaynak

Varsayılan `main` dalında şu anda proje tanıtımı bulunuyor; imzalı Android APK’sı ve kaynak proje arşivi [GitHub Releases](https://github.com/lezgindurmaz/KaranlikEv/releases) bölümünde yayımlanıyor.

> Bu depo açıklaması mevcut indirme dosyalarının yerine geçmez. Sürüm, uyumluluk ve değişiklik bilgileri için ilgili release notlarını kontrol edin.
